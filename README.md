# Tasnim Tanha — Creative Web Developer & UI/UX Architect

![Portfolio Preview](assets/about-section-exact.png)

A bespoke, high-performance creative portfolio website engineered with fluid 3D transformations, motion physics, and modern web design systems.

---

## 🌟 Key Features

- **118-Frame Smooth Background Canvas Scroll Engine:** Hardware-accelerated canvas renderer synchronized with user scroll momentum using Lenis smooth scroll.
- **Featured Projects 3D Folder Deck:** Radial 3D fan-out project carousel with coverflow depth transitions, touch/mouse drag inertia, and live project routing.
- **3D Cover Flow Skill Flashcards:** Interactive competencies flashcards with 3D perspective tilt, depth layers, and custom lighting.
- **How I Work (3D Cylindrical Process Ribbon):** 5-stage discovery-to-launch workflow deck on a 3D cylindrical horizon track.
- **What I Do (Services Rolling Drum):** Continuous 3D vertical drum with smooth wrap physics, momentum dampening, and mouse wheel rotation.
- **Fully Functional Contact Form:** Direct Gmail inbox delivery integrated via EmailJS v4 SDK with live input validation, shaking feedback, loading spinner, and success/error toasts.
- **Adaptive Mobile & Tablet Layout:** 100% responsive across smartphones, foldables, iPads, tablets, and high-DPI desktop screens with zero horizontal overflow.

## 🚀 One-Click Deployment to Vercel

This project is pre-configured and 100% optimized for **[Vercel](https://vercel.com/)** static hosting.

### Quick Deployment Steps:

1. Go to your **[Vercel Dashboard](https://vercel.com/new)**.
2. Click **"Add New..."** &rarr; **"Project"**.
3. Import your GitHub repository: `https://github.com/t-tasnim1524/tasnim-tanha`.
4. In the Project Configuration:
   - **Framework Preset:** `Other` (Auto-detected as Static HTML)
   - **Root Directory:** `./`
   - **Build Command:** *(Leave empty)*
   - **Output Directory:** `.` *(Leave default)*
5. Click **"Deploy"**.

Your portfolio will be live worldwide in seconds on Vercel's global edge network with instant cache invalidation and SSL!

## 🛠️ Local Development

To run the site locally:

```bash
# Clone the repository
git clone https://github.com/t-tasnim1524/tasnim-tanha.git

# Navigate into the project directory
cd tasnim-tanha

# Serve locally using any static web server, for example:
npx serve .
# or
python -m http.server 8000
```

Open `http://localhost:8000` or `http://localhost:3000` in your browser.
